# PAINT-THERE
一种绘制协议，用于控制远端渲染器如何绘制内容。


# WM
vm-desktop 是基于PAINT-THERE协议实现的一种桌面环境。
窗口管理器管理CLIENT的渲染资源，协议控制远端渲染器如何绘制。
支持运行基于JPX的窗口程序。


# 设计准则
- 协议不得显式暴露桌面结构与窗口的业务逻辑。
- 用单向协议提交`绘制`相关的一切事务，渲染器只是执行器。
- SSE下发，WS回传，各自独立通道。
